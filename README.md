# Глаша

**Глаша** — личный помощник и «освободитель головы»: одно место для личных дел, работы, календаря, денег, здоровья, обучения, документов, поездок, целей и мыслей.

## Текущий backend

Ветка `prototype/glasha-v1` уже содержит:
- Supabase auth, RLS и таблицы для задач, расходов, календаря, здоровья, целей, вложений и входящих мыслей;
- AI-router команд `/api/assistant`;
- серверную транскрипцию голоса `/api/voice/transcribe`;
- Советчик `/api/advisor`;
- приватные вложения к сущностям через Supabase Storage;
- PWA и отдельные иллюстрации Глаши.

## Политика моделей: качество по сложности, а не одна дорогая модель на всё

Это обязательный принцип проекта.

- **Рутинные команды** — `gpt-5.6-luna`: расходы, задачи, даты, категоризация, короткие запросы к данным.
- **Советчик по обычным вопросам** — тоже `gpt-5.6-luna`.
- **Сложные вопросы** — автоматически `gpt-5.6-terra`: длинный контекст, анализ вариантов, стратегия, документы, рискованные/сложные темы.
- **Голос** — `gpt-4o-mini-transcribe` как экономичный вариант.
- Более дорогая модель не должна вызываться без необходимости.

Центральная политика находится в `src/lib/model-policy.ts`, чтобы маршрутизация моделей не расползалась по коду.

Поддерживаемые переменные:
- `OPENAI_MODEL_FAST` — по умолчанию `gpt-5.6-luna`;
- `OPENAI_MODEL_DEEP` — по умолчанию `gpt-5.6-terra`;
- `OPENAI_TRANSCRIBE_MODEL` — по умолчанию `gpt-4o-mini-transcribe`.

Старые `OPENAI_MODEL` и `OPENAI_ADVISOR_MODEL` остаются fallback для совместимости.

## Статус

Без Supabase/OpenAI credentials интерфейс показывает режим настройки и не выдаёт демо-записи за реальные сохранённые данные.
